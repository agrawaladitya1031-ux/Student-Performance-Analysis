
# Student Performance Analysis

A Python project that analyzes student marks and summarizes academic performance.

## Features
- Calculates total marks and averages
- Assigns grades based on average marks
- Identifies the top-performing student
- Displays individual student reports

## Technologies Used
- Python
- Lists and dictionaries
- Loops and conditional statements
- Built-in functions such as sum()

## How to Run

Install Python 3, then run:

```bash
python student_analysis.py
```

## Concepts Demonstrated
- Data organization
- Basic calculations
- Conditional logic
- Finding maximum values
- Simple data analysis

## Future Improvements
- Read student records from a CSV file
- Allow users to enter marks
- Create charts to compare student performance
